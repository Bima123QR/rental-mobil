# Laju Rental Mobil

1. pgAdmin: buat database `rental_mobil`, buka Query Tool, jalankan `db/schema.sql` (F5).
2. Salin `.env.example` menjadi `.env`, isi `DB_PASSWORD`, `ADMIN_PASSWORD`, dan `WA_NUMBER`.
3. Terminal VS Code: `npm install` lalu `npm start`.
4. Pelanggan: http://localhost:3000  |  Admin: http://localhost:3000/admin.html

Catatan: `schema.sql` menghapus tabel lama. Jalankan hanya saat pertama kali atau untuk reset data.
